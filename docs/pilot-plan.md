# Piloto de 12 semanas

## Alcance

- una promoción;
- aproximadamente 150 viviendas;
- perfiles de Calidad, Postventa y Proveedor;
- integración inicial mediante CSV, API o webhook;
- baseline antes de activar la solución.

## Fases

1. **Semanas 1–2:** baseline, categorías, fuentes, permisos y mapa de proceso.
2. **Semanas 3–4:** configuración, checklists, SLA y formación.
3. **Semanas 5–10:** operación controlada, revisión humana y telemetría.
4. **Semanas 11–12:** comparación, revisión de casos y decisión go/no-go.

## Metas de evaluación

- −50 % en registro y clasificación;
- −20 % en incidencias incompletas;
- −15 % en tiempo de asignación;
- −10 % relativo en reaperturas o segundas visitas;
- 100 % de cierres con evidencia y trazabilidad;
- scorecard sustentada por incidentes revisables.

Son objetivos del piloto, no resultados conseguidos.
